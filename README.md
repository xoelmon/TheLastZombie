# TheLastZombie

Demo de acción/supervivencia desarrollada en Unity. Este repositorio contiene el proyecto Unity completo.

Demo jugable: https://lagartixa-soundlab.itch.io/
Autor: Xoel Mon López -- www.linkedin.com/in/xoelmonlopez/

---

# Sobre el proyecto

The Last Zombie es una demo corta en la que el jugador tiene que conseguir los cerebros perdidos y tener cuidado con
los soldados que lo están buscando.

Unity versión 6000.0.54f1 LTS 

---

# Objetivos

- Aprender el flujo de trabajo de Unity: escenas, prefabs, componentes
  y ciclo de vida de los scripts.
- Programar en C# las mecánicas principales del juego: movimiento del
  jugador, IA de enemigos, sistema de combate y gestión de estados.
- Comprender la arquitectura de un proyecto Unity: separación de scripts,
  managers, comunicación entre componentes.


Nota: los assets visuales y de audio utilizados son recursos libres de
terceros. Mi trabajo se centró en el diseño técnico y la programación.
